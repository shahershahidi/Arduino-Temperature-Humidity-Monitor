# Arduino Temperature and Humidity Monitor

## Project Overview
This project uses an Arduino UNO R3 to measure temperature and humidity using a DHT11 sensor. The readings are displayed on a 16x2 LCD screen and updated every 2 seconds.

## Components Used
- Arduino UNO R3
- DHT11 Temperature and Humidity Sensor
- LCD1602 Display with I2C Module
- Jumper Wires
- USB Cable

## Features
- Measures temperature in Celsius
- Measures humidity as a percentage
- Displays readings on an LCD screen
- Updates readings every 2 seconds
- Shows an error message if the sensor cannot be read

## Software
- C++
- Visual Studio Code
- PlatformIO
- Arduino Framework

## How It Works
1. The DHT11 sensor measures temperature and humidity.
2. The Arduino reads the sensor data.
3. The Arduino sends the readings to the LCD display.
4. The display updates every 2 seconds.
